# 制作说明

永雏小菲采用圆润的非像素动漫 Q 版风格。基础形象、动作条和转头姿势由内置 ImageGen 绘制，之后进行背景处理、整行动作的统一缩放对齐、图集拼装和检查。预览文字绘制在精灵格之外，未手绘或变形替换宠物像素。

本次公开版本采用已保存并重新下载核对的最新画面，包含左右跑步修复。摆臂固定、半周期领腿重复和中途回摆的源姿势已重新绘制或编辑；其他动作与转头方向沿用通过检查的版本。先逐帧和循环观察，再运行结构、背景及整体质量检查。

图像生成提示重点是：保持角色的脸、发色、服装、配饰、比例与光照；每个动作姿势完整连接且彼此分开；两条腿交替支撑和抬起，手臂随步态前后摆动；无文字、地面、阴影、速度线、散落特效或裁切。

发布文件只包含最终素材、预览和可公开的说明。详细可见限制见[质量说明](quality-notes.md)，真实数值检查结果见 [validation.json](../validation.json)。
